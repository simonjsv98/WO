# ODLA

En app för att planera och hålla koll på trädgårdslandet, för mobil och iPad. Samma känsla som RECIPES och KNIT.

- **LANDET** – landet i 3D (vrid, zooma, tryck på en bädd) och som karta ovanifrån med mått. Ett reglage visar hur det ser ut vid olika tider på säsongen. Med pennan flyttar du och ändrar storlek på bäddar; i varje bädd skriver du in exakta mått.
- **SÄSONG** – översikt över året, vad som ska göras månad för månad, växtföljd och vilka fröer som behövs.
- **DAGBOK** – sådd, utplantering, skörd (med mängd), vattning och anteckningar, per bädd och gröda.

Allt sparas lokalt och kan sparas som fil.

```bash
npx serve .          # eller valfri statisk server
npm install && npm run build   # bygger om scene.js efter ändringar i build/scene-src.js
```
